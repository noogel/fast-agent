## 目标与范围

构建一个可运行、可阅读、可逐步扩展的 Python Agent 教学项目。学习者能沿着“用户输入 → 模型决策 → 工具执行 → 结果回传 → 最终回答”理解完整链路，并能自行添加工具。项目位于 `/Users/xyz/MyProjects/awesome/fast-agent`，作为 awesome 仓库的普通子目录管理，不建立嵌套 Git 仓库。

用户已确认 Python、终端交互、OpenAI 兼容接口、基础文件与命令工具、模拟模式及中文教程。第一版不包含网页界面、多 Agent、向量数据库、流式响应、自动上下文压缩及远端部署。

## 技术选择

使用 Python 3.11 及以上、同步调用、普通函数和数据类。用官方 OpenAI Python SDK 适配 Chat Completions 工具调用协议，测试采用 pytest，终端交互使用标准库。依赖版本在实现时根据本机环境核实并记录。

选择手写 Agent 循环，而不引入 Agent 框架，以便学习者直接看到消息和控制流。相比直接手写 HTTP，SDK 减少与教学目标无关的传输细节；相比异步实现，同步调用便于单步调试。并非所有 OpenAI 兼容服务都支持工具调用，文档须说明真实模式需要支持 tools 的模型与服务。

## 模块边界

- `config.py`：读取和验证环境变量，不发起网络调用。
- `models.py`：定义消息、工具调用和模型回复数据结构。
- `providers.py`：统一模型接口，提供真实 OpenAI 兼容适配器和确定性的模拟适配器。
- `agent.py`：维护对话历史并实现循环，依赖模型接口和工具注册表，不依赖具体工具。
- `tools.py`：工具定义、参数校验、注册与调度，提供文件和命令工具。
- `cli.py`：参数解析、交互、确认与事件展示，不承担模型决策。

源码放在 `src/fast_agent/`，测试放在 `tests/`。提供 `pyproject.toml`、`.env.example`、`.gitignore`、中文 README、`docs/tutorial/` 和 `examples/`。`.env.example` 仅供配置参考，默认从进程环境读取配置，不暗中加载文件。实际密钥不进入仓库、日志或示例。

## 数据流与退出条件

1. CLI 创建工作目录上下文、模型适配器和 Agent，记录系统消息。
2. 每轮用户输入追加到历史，Agent 携带工具定义调用模型。
3. 模型返回普通文本且无工具调用时，展示最终回答并结束本轮。
4. 返回工具调用时，先保存模型消息，再按顺序执行每个工具，按调用 ID 写回工具结果。
5. 继续调用模型，直到生成最终回答，或达到每轮默认 10 次模型调用上限。

工具事件只展示工具名、必要参数、结果和错误，不声称展示模型隐藏思维链。CLI 支持退出、清空历史和 Ctrl+C 中断。达到步数上限时明确说明本轮未完成；保留结构有效的历史供用户继续操作。

## 工具与执行边界

- `read_file`：读取 UTF-8 文本；限制单次读取量，超限明确报错。
- `write_file`：创建或覆盖 UTF-8 文件，覆盖已有文件前获得用户确认。
- `edit_file`：以精确文本替换修改文件，要求目标唯一匹配，避免静默误改。
- `run_command`：接受程序及参数数组，通过 `subprocess` 执行，不默认使用 shell；设置工作目录、超时和输出上限。

所有文件路径先解析绝对路径和符号链接，再确认属于指定工作目录；拒绝越界及目录冒充文件。工作目录默认当前目录，可通过 CLI 指定。此约束是基础教学保护，不宣称抵抗并发符号链接替换等攻击。

命令执行统一要求交互确认，避免依赖不可靠的危险命令识别；非交互模式拒绝命令执行，不自动批准。命令可能访问工作目录以外的资源，因此工作目录约束不等于系统沙箱，文档明确说明。执行超时时终止命令进程组；输出采用有界读取，避免先无限缓存再截断。模拟演示只使用临时目录中的文件工具，不执行系统命令。

## 配置、错误和模拟模式

真实模式读取 `FAST_AGENT_API_KEY`、`FAST_AGENT_BASE_URL`、`FAST_AGENT_MODEL`。模型和密钥必须显式配置；地址默认 OpenAI API 地址。提供工作目录和步数上限参数。缺少配置时在请求前给出清晰提示，不展示密钥。模拟模式不需要上述配置且不访问网络。

未知工具、非法 JSON、参数类型错误、路径越界、缺失文件、用户拒绝及命令超时转为结构化工具结果，让模型有机会纠正。认证、网络或不支持工具协议等模型调用错误终止本轮并向用户解释，不伪造成功结果；不进行无上限重试。一个模型回复中的多个工具调用顺序执行并分别返回结果。

模拟适配器提供确定性的“读取示例文件 → 编辑内容 → 再次读取 → 回答”演示，验证工具结果后再总结。它是协议教学替身，不宣称具有自然语言推理能力。普通模拟对话清楚标识为模拟输出。

## 教学顺序

1. 单次模型调用：消息、配置和响应。
2. 工具定义：JSON Schema、参数、调用 ID 和结果。
3. Agent 循环：为何工具结果需要再次交给模型。
4. 文件工具与命令工具：边界、确认、失败恢复。
5. 多轮对话与可观察事件：区分模型回复和工具执行。
6. 自定义工具练习：添加工具并通过测试验证。

每章链接真实源码并提供可执行命令，区分需要 API Key 的示例和离线示例，避免另写一套与主实现漂移的教学代码。
