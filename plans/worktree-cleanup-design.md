# worktree 清理实现设计

这是七项收尾合同第 2 项的剩余工作，不以归档代替磁盘清理。

## 生命周期

1. 显式预览：只接受已确认归档的自建 worktree，拒绝未知移动状态、活动记录、链接、子模块、脏 Git 状态及未交付提交。
2. 把运行证据和忽略/未跟踪文件保存到主仓库独立证据包，记录文件路径、大小、SHA-256。Git 跟踪文件由可达提交恢复；提交必须在主仓库受保护引用中保留，不能依赖 detached HEAD 的偶然可达性。
3. 在清理前校验包内容和文件树清单，准备状态收据，再经用户明确确认执行 git worktree remove。不得为了删除绕过脏状态检查。
4. 删除后核对 Git 注册与目录状态，收据保留，不删除证据包。异常中断只允许核实，不自动重试删除。
5. 提供证据包查看与恢复入口，路径恢复拒绝覆盖现有文件及路径穿越。独立证据包的永久回收属于第 6 项引用保留策略。

## 必须测试

脏状态拒绝、独立提交拒绝或保护、未跟踪/忽略证据完整保留、证据损坏拒绝、确认期间变化拒绝、活动任务拒绝、删除中断核实、恢复字节一致、主目录无修改。使用临时 Git 仓库，不清理用户现有工作区。

此文件是下一阶段实现约束，不是已实现证据。
